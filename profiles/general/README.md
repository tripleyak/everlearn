# General Profile

Use this profile for broad personal knowledge capture.

Default capture types:

- `learning`: reusable lessons
- `decision`: choices and rationale
- `research`: source-backed synthesis
- `workflow`: repeatable processes
- `prompt`: prompts worth reusing

Suggested folders:

- `00 Inbox`
- `10 Learnings`
- `20 Decisions`
- `30 Research`
- `40 Workflows`
- `50 Sources`
- `60 Reviews`
