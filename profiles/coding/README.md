# Coding Profile

Use this profile for engineering work.

Default capture types:

- `learning`: repo patterns and implementation lessons
- `decision`: architecture decisions and tradeoffs
- `workflow`: runbooks, commands, and verification paths
- `research`: docs and dependency findings
- `prompt`: reusable coding prompts

- `coding`
