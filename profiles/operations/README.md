# Operations Profile

Use this profile for business processes, SOPs, and recurring reviews.

Default capture types:

- `workflow`: SOPs and repeatable processes
- `decision`: operating decisions and rationale
- `learning`: process lessons
- `review`: weekly or monthly operating reviews

Suggested tags:

- `operations`
- `sop`
- `handoff`
- `process`
- `review`
- `bottleneck`
