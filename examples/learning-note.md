# Use explicit capture before automation

## Capture

Start with explicit note capture before enabling automatic transcript or session mining.

## Why It Matters

- Explicit capture is easier to trust, explain, and teach.
- It avoids accidentally saving private or irrelevant material.

## Reuse

- Use this rule when introducing Everlearn to a new team or workshop group.
