# Everlearn Repo Instructions

Everlearn must stay local-first, portable, and readable by non-engineers.

- Do not add cloud dependencies for the core setup path.
- Do not scrape transcripts, caches, browser history, or private files by default.
- Keep workshop setup under five minutes on a fresh Mac.
- Keep scripts shell-based unless a stronger reason exists.
- Preserve compatibility with Claude Code, Codex, and shared `~/.agents/skills` installs.
- Never store secrets in example captures, fixtures, or docs.
